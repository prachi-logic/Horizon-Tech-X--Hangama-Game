# 🎮 Hangman Game

A simple and interactive Hangman Game built using Python. This project allows users to guess letters of a hidden word while tracking their remaining attempts. It demonstrates core Python programming concepts through a fun and engaging game.

## Features

* Random word selection
* Letter-by-letter guessing
* Limited attempts system
* Display of guessed letters
* Win and lose conditions
* User-friendly console interface

## Concepts Used

* Functions
* Lists
* Strings
* Loops
* Conditional Statements
* Random Module
* User Input/Output

## How the Game Works

1. A random word is selected.
2. The player guesses one letter at a time.
3. Correct guesses reveal letters in the word.
4. Incorrect guesses reduce the remaining attempts.
5. The game ends when:

   * The player guesses the complete word, or
   * All attempts are used.

## How to Run

1. Clone the repository
2. Open the project in Python
3. Run the script:

```bash
python hangman.py
```
